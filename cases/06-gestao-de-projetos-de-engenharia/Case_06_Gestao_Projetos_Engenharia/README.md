# Case 06 - Gestão de Projetos de Engenharia

Case sintético para treinamento em SQL, modelagem relacional, Excel, Power BI e análise de negócios.

## Arquivos

- `case_gestao_projetos_engenharia.xlsx`: planilha profissional com dashboard e tabelas.
- `case_gestao_projetos_engenharia.db`: banco SQLite pronto para consulta.
- `schema.sql`: DDL do modelo relacional.
- `consultas_sql.sql`: consultas de negócio comentadas.
- `diagrama_erd.svg`: diagrama entidade-relacionamento.
- `guia_gestao_projetos_engenharia.pdf`: briefing, KPIs, visões e perguntas.
- `case_e_desafios.md`: contexto e prompt profissional preenchido.
- `dicionario_dados.md`: definição das tabelas e regras.
- `relatorio_qualidade_dados.md`: verificações e limitações.
- `medidas_dax.txt`: medidas iniciais para Power BI.

## Uso sugerido

1. Explore a aba `Dashboard` no Excel.
2. Consulte o banco com DB Browser for SQLite, DBeaver ou Python.
3. Execute e adapte `consultas_sql.sql`.
4. Importe as tabelas no Power BI e construa as seis visões propostas.
5. Documente fatos, hipóteses e recomendações separadamente.

Todos os nomes e dados são fictícios e foram gerados apenas para fins educacionais.
