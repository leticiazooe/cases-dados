# Case 10 — Fontes de Energia

Projeto fictício para treinar Excel, SQL, modelagem relacional, Power BI e análise de negócio.
O pacote compara fontes renováveis e não renováveis por geração, capacidade, custos,
disponibilidade, emissões, contratos e investimentos. Dados sintéticos; corte em 30/06/2026.
