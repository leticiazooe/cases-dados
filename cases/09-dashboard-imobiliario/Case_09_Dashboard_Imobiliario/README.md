# Case 09 - Dashboard Imobiliário

Case fictício para SQL, Power BI, Excel e modelagem com preços, localização, metragem,
valorização, aluguel, vacância, anúncios, propostas e transações.

O banco SQLite contém os 36.000 registros do histórico de preços. Para manter a planilha
leve e adequada ao treinamento, o Excel contém uma amostra estruturada de 12.000 registros
desse histórico; as demais tabelas estão completas.
