# Qualidade dos dados

- Imóveis: 1200; históricos de preço: 36000.
- Anúncios: 2100; contratos: 950; vacâncias: 800.
- Integridade referencial validada.
- Datas finais nulas são esperadas para anúncios, contratos e vacâncias ainda ativos.
- Limitações: sem geocoordenadas exatas, condomínio, IPTU, financiamento detalhado ou custos de manutenção.
