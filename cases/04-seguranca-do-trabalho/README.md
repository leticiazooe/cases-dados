# Case - Segurança do Trabalho

Projeto fictício de dados com Excel, banco SQLite, SQL, ERD, dicionário e PDF.

## Objetivo

Integrar acidentes, quase-acidentes, riscos, EPIs, treinamentos, auditorias e planos de ação para prevenir ocorrências e fortalecer a cultura de segurança.

## Como usar

1. Explore o dashboard do Excel.
2. Abra o banco no DBeaver ou DB Browser for SQLite.
3. Execute as consultas SQL.
4. Importe as tabelas no Power BI.
5. Recrie os relacionamentos indicados no ERD.

Todos os dados são sintéticos.
