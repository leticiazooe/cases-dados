# Dicionário

- `dim_fonte_energia`: produto energético, grupo primário/secundário e classificação analítica.
- `dim_tempo`: totais anuais calculados para o recorte.
- `fato_fluxo_energetico`: ano, produto, operação e valores em 10³ tep.
- `valor_original_ben`: valor exatamente como publicado.
- `valor_ktep`: valor analítico, com exportações convertidas para módulo positivo.
- `dim_fonte_dados`: metadados de origem, licença, acesso e tratamento.
