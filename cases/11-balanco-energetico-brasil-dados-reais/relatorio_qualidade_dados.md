# Qualidade dos dados

- Fonte oficial consumida: EPE/BEN 2025.
- Período: 2010-2024; produtos: 25; fatos: 1125.
- Integridade referencial e banco SQLite validados.
- Sem valores nulos nas chaves e métricas principais.
- Valores zero são mantidos: podem representar inexistência, ausência de fluxo ou arredondamento da fonte.
- Classificação renovável/não renovável é uma camada analítica documentada, não uma coluna original do anexo.
- Limitação: tep mede energia física; não informa preço, valor FOB, país parceiro, NCM ou custos logísticos.
