# Prompt profissional - Segurança Industrial, LOTO e Ações Preventivas

Crie uma solução analítica para o processo de Segurança Industrial, LOTO e Ações Preventivas, com modelo relacional, dados sintéticos realistas, indicadores executivos e pipeline completo em Python e pandas. A origem deve conter problemas controlados de qualidade; o tratamento deve registrar rejeições, reconciliar os totais e publicar CSVs tratados e banco SQLite. Inclua Excel, SQL, DAX, ERD, dicionário e guia de apresentação.
