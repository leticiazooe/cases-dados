# Case 18 - Academia e Centro Esportivo

Case profissional fictício para treinamento em Excel, SQL, Power BI, modelagem relacional e consultoria de dados.

## Conteúdo
- Excel com dashboard e tabelas relacionadas
- Banco SQLite e schema SQL
- Consultas SQL
- Diagrama ERD
- Dicionário, qualidade, medidas DAX e prompt preenchido
- Guia profissional em PDF

Todos os dados são sintéticos.


## Versão Pipeline Completo
Este pacote inclui dados brutos com erros controlados, pipeline pandas executável, rejeitados, dados tratados de referência, banco reconstruído, notebook e relatório de reconciliação.
