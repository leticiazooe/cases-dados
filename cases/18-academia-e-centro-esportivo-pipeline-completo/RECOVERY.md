# Recuperação do Case 18

O ZIP histórico deste case estava truncado. Esta pasta foi reconstruída preservando os arquivos íntegros encontrados e regenerando apenas os artefatos derivados que estavam após o ponto de truncamento.

## Preservado

- base SQLite original
- planilha Excel original
- dados brutos preservados
- arquivos rejeitados preservados
- consultas SQL preservadas

## Regenerado

- CSVs tratados e de referência, exportados da base SQLite preservada
- schema SQL
- dicionário e relatórios de pipeline
- ERD em SVG
- medidas DAX de apoio
- arquivos auxiliares do laboratório pandas
- guia PDF de recuperação

Nenhum dado sintético-base foi inventado durante a recuperação dos CSVs tratados.
