# Cases de Dados

Coleção de 24 projetos completos para estudos e portfólio em análise de dados, engenharia de dados, SQL, Power BI, Excel e Python.

Cada case está disponível como um pacote ZIP independente. Os pacotes incluem, conforme o tema, bases em CSV/Excel, banco SQLite, scripts SQL, medidas DAX, documentação, diagrama ERD, relatório de qualidade e materiais para construção de pipelines.

## Como usar

1. Baixe o ZIP do case desejado.
2. Extraia o conteúdo em uma pasta própria.
3. Leia o README e o guia incluídos no pacote.
4. Execute o pipeline ou importe as bases no Excel, SQLite, Python ou Power BI.

## Observações

- Os dados sintéticos são destinados a estudo e demonstração.
- O Case 11 utiliza dados públicos reais e inclui as fontes no próprio pacote.
- Os Cases 15 a 18 são as versões refeitas para pipeline completo.
- Não utilize dados fictícios destes projetos para decisões clínicas, jurídicas, financeiras ou operacionais reais.
